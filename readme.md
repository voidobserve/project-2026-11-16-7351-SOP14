
## 脚位和功能

| 引脚编号 | 名称 | 功能描述                                                   | 补充                                                                                                                               |
| -------- | ---- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 1        | VDD  |                                                            |
| 2        | P15  | NC                                                         |
| 3        | P14  | 白灯负极，低电平点亮                                       |
| 4        | P13  | NC                                                         |
| 5        | P16  | 控制正向的PWM                                              |
| 6        | P17  | 控制反向的PWM                                              |
| 7        | P12  | 加热控制                                                   |
| 8        | P11  | 检测加热按键是否按下                                       |
| 9        | P04  | 红灯负极，低电平点亮                                       |
| 10       | P03  | 连接到`充电芯片`的2脚                                      | 充电状态指示引脚。<br>开漏输出，通过限流电阻接LED灯至VDD，可以指示充电过程。<br>充电，灯亮(低电平)；充满，灯灭(芯片引脚为高阻态)。 |
| 11       | P02  | 检测电池分压后的电压，外部**470K**下拉，1M上拉至BAT+       |
| 12       | P01  | 按键SW2 (开关和模式按键)                                   |
| 13       | P00  | 检测是否有充电的电压，外部3K下拉，3.3K上拉至type-c的5V输入 |
| 14       |      | GND                                                        |

 
- 充电芯片使用的是`5052A-ESOP10L`

## 实测标定（2026-11-17，空板未焊主控、不接电池、插充电器）

| 测点 | 实测 | 说明 |
| --- | --- | --- |
| 11 脚 P02 | 2.61 V | 反算 BAT+ = 2.61 × (1000+470)/470 ≈ 8.16 V → 分压确认为 **470K/1M**（原表写的 70K 有误） |
| 13 脚 P00 | 2.54 V | 插入充电器可判为高电平；配置字 `SMTVS` 必须选 2.0V/0.8V（0.8VDD=2.64V 会把 2.54V 判成低） |
| 10 脚 P03 | 一直低 | 无电池时 5052A 不会报"充满"，P03 不会变高 |

- 固件对应阈值（12 位 ADC、内部 3V 参考）：6.5 V → **2837**，6.2 V → **2706**，芯片空载 CV(8.16 V) → 约 **3564**。
- 分压比 470K/(470K+1M) ≈ 0.3197，代码中由 `BAT_DIVIDER_TOP_KOHM` / `BAT_DIVIDER_BOTTOM_KOHM` 两个宏推算，改电阻只需改这两个宏。
